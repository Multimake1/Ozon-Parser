# Ozon Parser
Парсер для сбора данных о товарах с маркетплейса Ozon.
# Возможности
- Автоматическое и ручное получение cookies с data.ozon.ru
- Парсинг товаров по SKU
- Сохранение в CSV
# Инструкция
Сначало нужно запускать модуль get_cookies - это универсальный сбор куки 
Запускается автоматический метод сбора с помощью кода на почту gmail, но если вход по qr коду или звонку, то войти не получится и автоматически включиться ручной режим входа в аккаунт где нужно самостоятельно пройти аутентификацию
Можно миновать автоматический сбор и самостоятельно собрать куки запустив модуль manual_auth и ввести все в ручную
После получения куки можно запускать модуль parse_ozon для парснига товаров по SKU
